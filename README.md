# DNA Sequence Analysis Using Python

A beginner-friendly bioinformatics project for analyzing DNA sequences using Python. The project performs basic sequence validation, nucleotide composition analysis, GC content calculation, sequence reversal, and extraction of the last six nucleotides.

## Project Overview

DNA sequence analysis is an important part of bioinformatics. This project demonstrates how basic Python programming concepts can be applied to biological sequence data.

The program takes a DNA sequence as input and performs several fundamental sequence analysis operations.

## Features

- DNA sequence validation
- Nucleotide composition analysis
- Counting A, T, G, and C nucleotides
- GC content calculation
- Reverse DNA sequence
- Extraction of the last six nucleotides

## Workflow

1. Define a DNA sequence.
2. Validate the sequence using the four standard DNA bases: A, T, G, and C.
3. Count the occurrence of each nucleotide.
4. Calculate the GC content.
5. Generate the reverse sequence.
6. Extract the last six nucleotides.
7. Display the analysis results.
